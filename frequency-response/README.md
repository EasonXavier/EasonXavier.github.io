# Acoustic Lab — iPhone 频响测试器

纯静态 HTML/CSS/JavaScript，使用 Web Audio API 和 `getUserMedia` 在浏览器本地进行简易测量。

## 功能

- 40–16,000 Hz、1/3 倍频程附近的离散正弦扫频；自动采集麦克风输入频点能量
- 以 1 kHz 归一化的相对频响曲线
- 实时 1/3 倍频程 RTA（输入为未校准 dBFS）
- 正弦波 / 粉红噪声信号发生器
- 参考曲线保存在本设备浏览器 `localStorage` 中；前后对比；CSV 和 PNG 导出
- 零依赖、零服务器端接口、无需构建步骤

## 使用

1. 用 iPhone Safari 打开 HTTPS 站点，点击「启用麦克风」，允许权限。
2. **推荐**使用外部音箱在另一台设备播放粉红噪声，iPhone 选择「实时频谱 RTA」监听。固定音量、测试点和朝向。
3. 「自动扫频」会让同一浏览器一边播放正弦音、一边通过麦克风采集。它是概略对比工具，不适合绝对校准。测量时保持屏幕常亮、页面处于前台。
4. 保存参考曲线后再次测量，就可以看到差值并导出数据。

## 频率测量说明

扫频在每个频点保留稳定时间，然后对 Web Audio `AnalyserNode` 的频谱进行多次采样，取频率附近频谱功率的中位数（`10*log10(sum(10^(bin_dB/10)))`），最终减去本次 1 kHz 的参考值。此方法用于**相对频率响应估计**，不是冲激响应反卷积，也不测量延迟、混响时间、相位、绝对声压级或声学传递函数。

RTA 使用对数频段（近似 1/3 倍频程）的频谱功率求和，显示的是未经校准的 `dBFS`，不是 `dB SPL`。低于设备底噪的频点不可信。

## 技术限制

- iPhone 内置麦克风和输出扬声器均有非平坦频响、动态处理与不透明的硬件/系统 DSP。
- iOS Safari 同时录音/播放可能改变输出路由，部分 iOS 27 版本存在杂音/听筒路由异常；即使要求 `echoCancellation`, `noiseSuppression`, `autoGainControl` 关闭，系统也不保证完整关闭 DSP。
- 不向任何服务器上传音频。参考曲线只留在浏览器本地。清除浏览器数据会清除参考数据。
- 不建议使用高音量；本工具不用于专业的音箱验收或分频器校准。需要专业结果可使用 REW 与经过校准的测量麦克风。
