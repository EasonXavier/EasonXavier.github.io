# Acoustic Lab — iPhone 频响测试器 v1.1

纯静态网页，运行在 GitHub Pages / Safari；使用 Web Audio API、getUserMedia，音频仅在浏览器本地分析。

## 双机自动扫频（推荐）

1. **收音 iPhone：** 打开 https://easonx.me/frequency-response/?role=receiver ，允许麦克风权限，点击「准备收音 · 自动同步」。不要连接蓝牙耳机，以免系统使用耳机麦克风。
2. **播放设备：** 在另一台 iPhone、iPad 或电脑打开 https://easonx.me/frequency-response/?role=player ，连接待测扬声器。iOS 蓝牙/AirPlay 通过控制中心选择输出；网页无法强制选择音频设备。
3. **播放端**调低音响和系统音量，点击「播放双机扫频」。它不会请求麦克风权限，通常可避免触发通话音频路由。
4. 播放端发出 1,800 Hz、1.25 秒的同步信标，静音 0.60 秒，接着按固定顺序播放 40–16,000 Hz 共 27 个离散正弦频点，每点 1.30 秒，约 37 秒完成。
5. 收音端自动识别声学信标；对每个频点中后段的频谱功率采样取中位数。完成后呈现以 1 kHz 为 0 dB 的相对频响曲线，支持参考曲线保存、CSV/PNG 导出。

**同步原理：** 两台设备不需要互联，收音端使用实际听到的声学同步信标作为计时起点，尽量消除设备时钟差和固定播放延迟。声学传播、FFT 缓冲、动态音频处理和浏览器定时抖动仍可能影响精度。测量时两端都必须保持页面前台；信标不能被明显噪声遮挡。

## 其他模式

- **单机测试**：一台 iPhone 同时播放和收音，iOS Safari 可能切换至听筒，结果仅作粗略对比。
- **实时 RTA**：收音端切换「实时频谱 RTA」，播放端可连续播放粉红噪声分析频段起伏。
- **独立信号发生器**：播放端提供正弦波和粉红噪声，无需开启麦克风，可使用系统选定的蓝牙输出。

## 计量和隐私限制

- 使用未经校准的 iPhone 麦克风，输出相对 dB，并非 dB SPL。
- 不能保证关闭系统的回声消除、降噪、自动增益及所有硬件 DSP。
- 不测量相位、脉冲响应、RT60、时延或专业意义上的绝对声学传递函数。
- 蓝牙音频的动态压缩与传输编解码可能影响频率响应。有条件时优先使用固定电平的有线输出。
- 所有采集数据只在当前浏览器处理，参考曲线存储在本地 localStorage，不上传录音。
- GitHub Pages 的 HTTPS 访问是开启麦克风的必要条件。
